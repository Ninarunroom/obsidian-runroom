# Resumen procesado — Next steps nueva web (01/09/2026)

Reunión de lanzamiento: la web nueva de Spradling sale en banner de construcción, con lanzamiento oficial fijado para el 10/09/2026 (acceso anticipado 6/09, VIP/interno 7/09). Se decide posponer el relanzamiento de las campañas de pago al **14/09/2026** para dar tiempo a validar conversiones.

Punto más importante para seguimiento: a esta fecha, la vinculación técnica entre UTMs de campaña y SugarCRM **seguía sin resolverse** (arrastrado desde la reunión de enero) — Sugar registra la conversión pero no el origen (UTM) detrás, lo que puede sesgar los reportes de atribución hacia "directo". Queda pendiente la reunión con Redka (proveedor de Sugar) para resolverlo, y el acceso a GTM para el equipo de Colombia. Mientras tanto, solo tiene sentido validar el flujo de usuario/formularios (CTA), no las UTMs en sí.
