# Spradling - next steps nueva web — 01/09/2026

**Invitados:** Nina Gotós, Araceli Iglesias (Runroom); d.estefa@spradling.group, Natalia Cortes (Spradling Europe)

## Resumen
El sitio nuevo está en banner de "construcción" durante la migración. Cronograma de lanzamiento: acceso anticipado 6/09 (domingo), lanzamiento a usuarios VIP/internos el 7/09 (lunes), comunicación oficial al resto del mundo el 10/09 (jueves). Se decide posponer el relanzamiento de campañas al **14 de septiembre** para validar bien conversión y flujo de usuario antes de invertir en medios.

## Decisión acordada
Aplazar el lanzamiento de campañas al 14/09/2026 para permitir pruebas de conversión y validaciones en la web nueva.

## Detalles
- Campañas actuales ya detenidas desde antes del banner de construcción (para no desperdiciar inversión sin web activa).
- Documento Excel de mapeo de URLs/campañas: existía dificultad de acceso (permisos SharePoint/Gmail); se acuerda compartirlo vía Google Docs, accesible también al equipo de Colombia.
- Creación de eventos/IDs de conversión: tarea de Runroom, pendiente esa semana, para que Colombia pueda avanzar con la implementación en GTM.
- **Punto crítico aún no resuelto:** la vinculación técnica entre los parámetros UTM y SugarCRM **no estaba hecha** a esta fecha — Sugar recogía la conversión por CTA/formulario, pero no la información de UTM detrás. Sin esto, no tiene sentido hacer pruebas de conversión por UTM todavía; se puede avanzar mientras tanto con pruebas de flujo de usuario/CTA (que los nuevos formularios registren el evento correcto).
- Reunión con Redka (proveedor de Sugar) sigue pendiente de agendar para resolver esta vinculación — se intentará acelerar para la semana siguiente.
- Acceso a Google Tag Manager (GTM) para el equipo de Colombia: pendiente de compartir (correos/usuarios) por parte de Runroom.
- Reunión con el equipo de Colombia para revisar el setup global de Analytics: urgente, programar esa misma semana (Marta se reincorporaba de vacaciones).
- Objetivo de fondo: con la nueva web + trazabilidad CRM, obtener datos para mejorar eficiencia, reducir costes y recuperar niveles de rendimiento de 2023.
